# Eng. Rewan ElBadry — Claude AI Packages

صفحة تفاعلية لباقات تعليم Claude AI والأتمتة.

- `index.html`: الصفحة نفسها (تتفتح في أي متصفح أو على GitHub Pages)
- `app.py`: تشغيل الصفحة على Streamlit

## التشغيل على Streamlit

```bash
pip install -r requirements.txt
streamlit run app.py
```

على Streamlit Community Cloud اختاري الريبو وحطي `app.py` كـ Main file.
